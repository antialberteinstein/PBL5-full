================================================================================
  PBL5 - HỆ THỐNG ĐIỂM DANH BẰNG NHẬN DIỆN KHUÔN MẶT (Face Recognition Attendance System)
================================================================================

Dự án PBL5 là một hệ thống điểm danh sinh viên sử dụng công nghệ nhận diện
khuôn mặt (Face Recognition). Hệ thống gồm 3 phần chính:
  1. AI API (Python/FastAPI) - Xử lý nhận diện khuôn mặt
  2. Backend API (Java/Spring Boot) - Xử lý logic nghiệp vụ
  3. Frontend (React/Vite) - Giao diện người dùng

================================================================================
  KIẾN TRÚC TỔNG QUAN
================================================================================

  [Frontend React :5173] --(HTTP/REST)--> [Backend Spring Boot :8080] --(MySQL)--> [Database pbl5]
                         \                                          /
                          `--(WebSocket/HTTP)-->  [AI FastAPI :8000]

- Frontend gọi Backend qua REST API (port 8080)
- Frontend cũng gọi trực tiếp AI API (port 8000) cho việc nhận diện khuôn mặt
- Backend kết nối MySQL database "pbl5"
- AI API sử dụng Milvus (vector database) để lưu/tìm kiếm face embeddings

================================================================================
  CƠ SỞ DỮ LIỆU (MySQL - Database: pbl5)
================================================================================

Các bảng chính:

1. profile          - Thông tin cá nhân (id, avatar_path, birth, full_name, email)
2. users            - Tài khoản đăng nhập (username PK, enabled, password, profile_id FK)
3. authority        - Phân quyền (authority, username) - VD: ROLE_ADMIN, ROLE_TEACHER, ROLE_STUDENT
4. teacher          - Giáo viên (id, username FK)
5. student          - Sinh viên (id, username FK, face_registered)
6. class            - Lớp học (id, name, teacher_id FK)
7. student_class    - Quan hệ sinh viên-lớp (id, class_id FK, student_id FK, status: PENDING/APPROVED/REJECTED)
8. attendance       - Buổi điểm danh (id, datetime, class_id FK)
9. student_attendance - Chi tiết điểm danh (id, attendance_id FK, student_id FK, checkin_time, image_url)
10. notification    - Thông báo (id, content, date, title)
11. user_notification - Thông báo cho user (notification_id FK, username FK, is_read)

Quan hệ:
- 1 User có 1 Profile
- 1 User có nhiều Authority (roles)
- 1 User có thể là Teacher hoặc Student
- 1 Teacher quản lý nhiều Class
- 1 Class có nhiều Student thông qua student_class (với trạng thái PENDING/APPROVED/REJECTED)
- 1 Class có nhiều buổi Attendance
- 1 Attendance có nhiều StudentAttendance records

--- API Endpoints ---
1. WebSocket /register  - Đăng ký khuôn mặt sinh viên (stream video từ webcam)
2. WebSocket /verify    - Xác minh khuôn mặt để điểm danh (stream video từ webcam local)

--- Luồng xử lý AI ---
1. ĐĂNG KÝ KHUÔN MẶT:
   - Nhận stream video từ webcam → Detect face (InsightFace)
   - Trích xuất face embedding (512-dim vector)
   - Preprocessing: PCA reduce dimension → Scale → Normalize
   - Lưu embedding vào Milvus vector DB với student_id

2. XÁC MINH KHUÔN MẶT (ĐIỂM DANH):
   - Nhận stream video từ webcam → Detect face (InsightFace)
   - Anti-spoofing check (DeepFace) → Chống giả mạo bằng ảnh/video
   - Trích xuất face embedding
   - Preprocessing → Tìm kiếm embedding gần nhất trong Milvus (cosine similarity)
   - Trả về student_id nếu match (vượt threshold)

1. ĐĂNG KÝ TÀI KHOẢN:
   User → Register → Nhập thông tin → Backend tạo account (enabled=false)
   → Gửi OTP qua email → User nhập OTP → Backend verify → enabled=true
   → Redirect Login

2. ĐĂNG NHẬP:
   User → Login → Backend validate → Trả JWT token + role
   → Frontend lưu token → Redirect Dashboard

3. ĐĂNG KÝ KHUÔN MẶT (Student):
   Student → FaceRegistration → WebSocket tới AI API → Stream webcam
   → AI detect face → Trích xuất embedding → Lưu vào Milvus DB
   → Đánh dấu face_registered=true

4. ĐIỂM DANH:
   a) Teacher tạo buổi điểm danh (chọn lớp, ngày giờ)
   b) Student mở trang ClassDetail → Bấm "Check in"
   c) Frontend kết nối AI API → Stream webcam → AI verify face
   d) AI trả kết quả (match/not match + student_id)
   e) Frontend gửi kết quả điểm danh lên Backend
   f) Backend lưu record StudentAttendance

5. QUẢN LÝ LỚP HỌC:
   - Teacher tạo lớp → Student xin vào (PENDING) → Teacher duyệt (APPROVED)
   - Teacher có thể import danh sách SV từ file Excel
   - Teacher xem lịch sử điểm danh, xuất báo cáo

================================================================================
  CÁCH CHẠY DỰ ÁN
================================================================================

Yêu cầu: Python 3.x, Java 21, Node.js, MySQL

1) Khởi tạo Database:
   - Tạo database MySQL "pbl5" (hoặc import file pbl5-mysql-workbench.sql)
   - Cấu hình connection trong backend/src/main/resources/application.properties

2) Chạy AI API:
   cd ai
   python -m venv .venv
   source .venv/bin/activate       # Linux/Mac
   .venv\Scripts\activate          # Windows
   pip install -r requirements.txt
   PYTHONPATH=src python src/api/app.py
   → http://127.0.0.1:8000

3) Chạy Backend:
   cd backend
   ./mvnw spring-boot:run          # Linux/Mac
   mvnw.cmd spring-boot:run        # Windows
   → http://127.0.0.1:8080

4) Chạy Frontend:
   cd frontend
   npm install
   npm run dev
   → http://127.0.0.1:5173

  CÔNG NGHỆ SỬ DỤNG (TECH STACK)

| Thành phần     | Công nghệ                                              |

| Frontend       | React 18, Vite 5, TailwindCSS 3.4, Axios, React Router |

| Build Tools    | Maven (backend), Vite (frontend), pip (AI)              |

================================================================================
  GHI CHÚ QUAN TRỌNG
================================================================================

- Hệ thống có 3 role: ADMIN, TEACHER, STUDENT
- JWT token được gửi trong header "Authorization: Bearer <token>"
- Frontend gọi Backend API qua http://localhost:8080/api
- Frontend gọi AI API trực tiếp qua http://127.0.0.1:8000
- Face embeddings được lưu trong Milvus vector database (không phải MySQL)
- Anti-spoofing giúp chống gian lận bằng ảnh/video giả
- Hệ thống hỗ trợ import danh sách sinh viên từ file Excel
- OTP được gửi qua Gmail SMTP khi đăng ký tài khoản
- Spring Security bảo vệ các endpoint theo role
- Hibernate ddl-auto=update (tự tạo/cập nhật bảng DB)
